# แถบกระจก รายการของฉัน และหมวดย่อย

ชุดอัปเดตสะสม รวมแก้มือถือ โปรไฟล์ไรเดอร์ ระบบตรวจรูป ตลาด แผนที่ และรีวิวจากชุดก่อน

## ติดตั้ง 3 ขั้นตอน
1. แตก ZIP จะได้โฟลเดอร์ kranuan-system
2. ที่หน้าแรก GitHub repository kranuanonlinecomunity เลือก Add file > Upload files ลากโฟลเดอร์ kranuan-system ลงไป แล้ว Commit changes
3. รอ Render Live แล้วปิดหน้าแอป/LIFF และเปิดใหม่ หรือรีเฟรช Ctrl+Shift+R บนคอม

ไม่ต้องเปลี่ยนค่า Firebase/Render และไม่เปิด Rules สาธารณะ

## แถบล่างและช่องไฟ
แถบล่างสูงประมาณ 64px มี 4 ปุ่ม: หน้าแรก รายการของฉัน ข่าวชุมชน เรียกไรเดอร์ ลอยชิดขอบล่างโดยคิด safe area เพียงครั้งเดียว ไม่เพิ่มช่องว่างภายในซ้ำ ลักษณะกระจกโปร่งเบลอและเงาบาง คงโทนส้มและไอคอน SVG เดิม เมนูตลาดอยู่กับกลุ่มปุ่มด้านบนเท่านั้น ลดช่องไฟระหว่างหมวดบน หัวข้อ และเนื้อหา รวมทั้งย่อข้อความแจ้งเตือนให้กระชับ

## รายการของฉัน
รวมคำสั่งซื้อ/เรียกไรเดอร์ โพสต์ในตลาด ความคิดเห็น รีวิวร้าน คะแนนไรเดอร์ และการแจ้งทิป เป็นแถวภาพเล็กพร้อมรายละเอียดและสถานะ กรองทั้งหมด ออเดอร์ โพสต์ กิจกรรม ได้ แตะออเดอร์เพื่อดูรายละเอียดเดิม แอนิเมชันติดตาม ประวัติ ยกเลิกตามสิทธิ์ และปุ่มให้คะแนน/แจ้งทิปเมื่อส่งสำเร็จ

ประวัติแสดงย้อนหลัง 72 ชั่วโมงจากกิจกรรมล่าสุด ระบบนำรายการที่หมดอายุออกจากหน้าผู้ใช้เมื่อโหลดข้อมูลหรือรีเฟรชอัตโนมัติ งานที่ยังไม่จบแสดงต่อแม้เกิน 3 วัน เพื่อไม่ให้ติดตามงานไม่ได้ ไม่ได้ลบออเดอร์จริงหรือประกาศขายจริงออกจากฐานข้อมูล ผู้ดูแลยังตรวจสอบได้ การแจ้งทิปยังเป็นความตั้งใจ ไม่ใช่การชำระหรือโอนเงินจริง

## หมวดย่อย
อาหาร: ทั้งหมด อาหารตามสั่ง ก๋วยเตี๋ยว หมูกระทะ หม่าล่า ส้มตำ/อีสาน ชาบู/ปิ้งย่าง ญี่ปุ่น/เกาหลี ขนม/เบเกอรี่ อื่น ๆ
เครื่องดื่ม: ทั้งหมด กาแฟ ชา/ชานม น้ำผลไม้ อื่น ๆ
ร้านค้า: ทั้งหมด ของชำ/ของใช้ เสื้อผ้า ไอที/อุปกรณ์ สุขภาพ อื่น ๆ
บริการ: คงหมวด SVG 12 ปุ่มจากชุดก่อน

หมวดย่อยอยู่ใกล้รายการร้านและกลุ่มหมวดหลัก เป็นแถบเลื่อนแนวนอนขนาดเล็ก จัดกลุ่มจากชื่อร้านและชื่อเมนูจริง ร้านอาจเข้าหลายหมวดได้ หากข้อมูลไม่ชัดเจนอยู่ในอื่น ๆ ไม่สร้างร้านหรือรูปทดลอง

## ตรวจสอบ
ผ่าน API ประวัติส่วนตัว 72 ชั่วโมง ซ่อนประวัติที่หมดอายุ เก็บงานที่ดำเนินการ ไม่ลบข้อมูลหลัก อ่านรายละเอียดเฉพาะเจ้าของ/ผู้มีสิทธิ์ บันทึกกิจกรรมโพสต์ และบังคับเข้าสู่ระบบ
ผ่านการทดสอบเดิม: อาหาร ส่งของ ส่งคน ตลาด สต็อก รับงานไม่ซ้ำ โปรไฟล์และรูปไรเดอร์ รีวิวร้าน
ผ่านการแยกหมวดย่อยตัวอย่างชื่อร้าน/ชื่อเมนู และตรวจไวยากรณ์สคริปต์ในชุดส่งมอบ
ยังไม่ได้ติดตั้งบนเว็บจริง และยังไม่ได้ตรวจภาพบนมือถือจริงในรอบนี้ หลัง deploy กรุณาปิดและเปิดแอปใหม่เพื่อโหลด CSS ชุดใหม่
