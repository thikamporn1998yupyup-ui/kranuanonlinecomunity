## วิธีอัปเดต

1. แตก ZIP นี้ จะมีโฟลเดอร์ kranuan-system
2. เปิด GitHub repository kranuanonlinecomunity ที่หน้า root (ก่อนเข้าโฟลเดอร์ kranuan-system)
3. กด Add file > Upload files แล้วลากโฟลเดอร์ kranuan-system ที่แตกออกมาลงไป เพื่อให้ไฟล์อยู่ใน path kranuan-system/server.cjs และ kranuan-system/public/... ตามเดิม
4. Commit changes แล้วรอ Render deploy ถ้าไม่ได้เปิด auto deploy ให้กด Manual Deploy > Deploy latest commit ที่ Service ID ด้านบน

## สิ่งที่เปลี่ยน

- หน้าร้านเป็นกริดรูป 16:9 เมนูรูปจัตุรัส ขนาดการ์ดเสมอกัน
- ปุ่มแก้ไขหน้าร้านเด่นชัด อัปโหลดภาพจากเครื่อง เปลี่ยนชื่อ หมวด ที่อยู่ พิกัด เบอร์โทรได้
- รูปถูกครอปและย่อในเครื่องก่อนบันทึก ไม่เพิ่ม Firebase Storage หรือบริการเสียเงิน
- หน้าเมนูผู้ดูแลแสดงภาพ ราคา และสถานะพร้อมขาย กดการ์ดเพื่อแก้ไขหรือเปลี่ยนรูป
- นำเข้า JSON ดูตัวอย่างรูปและเมนูได้ก่อนบันทึก นำเข้าเฉพาะเมนูเข้าร้านเดิมได้
- นำเข้ารูปจาก image_url, photo_url, image หรือ images[0] และแท็ก image/wikimedia_commons ที่ต้นทาง OSM ระบุไว้
- ถ้าพบ source_id เดิม หรือชื่อและที่อยู่ตรงกัน จะเติมเฉพาะรูปที่ขาด ไม่ทับภาพ/ราคาที่แก้ไว้ เมนูใหม่พักขายก่อน
- จัดหมวดอัตโนมัติจากประเภทต้นทางและคำในชื่อร้าน ถ้าระบุหมวดไทยมาในไฟล์จะใช้หมวดนั้น หากไม่ชัดเจนจะจัดร้านค้าพร้อมข้อความให้ตรวจสอบในตัวอย่างก่อนนำเข้า
- ไอคอนหมวดหมู่ SVG ทั้งหมด ไม่มีอิโมจิในหน้าลูกค้าที่อัปเดต
- เลือกเมนูด้วยปุ่มเพิ่ม–ลดจำนวน ตะกร้ารวมยอดติดด้านล่าง ขั้นถัดไปเป็นที่อยู่และยืนยัน
- จดจำชื่อ เบอร์โทร ที่อยู่และพิกัดในเบราว์เซอร์และเครื่องเดิมเมื่อเลือกจดจำ กดลบได้ ไม่ได้ซิงก์ที่อยู่ข้ามเครื่อง
- เปลี่ยนที่อยู่แล้วจะล้างพิกัดเก่า เพื่อไม่ส่งไรเดอร์ไปยังจุดเดิมโดยไม่ตั้งใจ
- แถบสถานะ 5 ขั้น สีและภาพ SVG เคลื่อนไหวตามสถานะจริง: รอร้าน, หาไรเดอร์, ไปรับของ, กำลังส่ง, สำเร็จ พร้อมสถานะยกเลิก และรองรับ reduced motion

## ทำไมบางร้านยังไม่มีภาพหรือเมนู

OpenStreetMap ไม่ใช่ฐานข้อมูลรูปอาหารหรือเมนูขายของทุกแห่ง ถ้าต้นทางไม่มี image หรือ wikimedia_commons จะไม่มีภาพให้ดึง และไม่สามารถอนุมานชื่อเมนูหรือราคาจากชื่อร้านได้

สำหรับร้านที่ไม่มีภาพ: แอดมิน > ร้านค้า > แก้ไขหน้าร้าน > เลือกรูปจากเครื่อง > บันทึก
สำหรับเมนู: รูปและเมนู > เพิ่มเมนู หรือกดเมนูเดิม > เลือกรูป > ระบุราคา > เปิดพร้อมขายเมื่อได้ตรวจแล้ว
สำหรับเมนูจำนวนมาก: ใช้ไฟล์ JSON จากร้านที่ระบุ name, price และ image_url แล้วตรวจตัวอย่างก่อนนำเข้า

ไฟล์ใน examples เป็นแม่แบบ ต้องเปลี่ยนเป็นข้อมูลจริงก่อนนำเข้า ใช้ลิงก์ HTTPS ของภาพจริงที่มีสิทธิ์ใช้ เว้นว่างได้ถ้ารอตั้งภาพภายหลัง อย่านำภาพร้านอื่นมาใส่แทน

## ผลการตรวจในเครื่อง

ตรวจไวยากรณ์ JavaScript ผ่าน ตรวจ API นำเข้าภาพและเมนู, preview ไม่บันทึกข้อมูล, กันรายการซ้ำ, สถานะร้านไม่เปิดอัตโนมัติ, เมนูพักขายก่อน, หมวดจาก OSM/ชื่อร้าน, ปฏิเสธราคาไม่ถูกต้อง และขั้นตอนเปิดร้านเดิมผ่าน
ตรวจผ่านเบราว์เซอร์ทั้งหน้าแอดมินและหน้าลูกค้า รวมการบันทึกภาพหน้าร้าน สั่งอาหาร ยอดรวม ที่อยู่และพิกัดที่จำไว้ในรอบถัดไป หน้าตัวอย่างนำเข้าภาพ และไม่มี JavaScript error ในหน้าแอดมินที่ตรวจ
ตรวจสถานะผ่าน API จาก ready > assigned > picked ผ่าน ข้อมูลและภาพทดสอบทั้งหมดอยู่ในเครื่อง ไม่ได้ใส่ในฐานข้อมูลจริง

ยังไม่ได้อัปโหลด GitHub หรือ deploy เว็บจริงในรอบนี้
