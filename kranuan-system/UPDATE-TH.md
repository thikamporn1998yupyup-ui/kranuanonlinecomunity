# อัปเดตรูปพนักงานและแดชบอร์ดผู้ดูแล

ใช้วางทับระบบเดิม รวมอัปเดตตลาด/เรียกรถจากชุดก่อนแล้ว ไม่ต้องติดตั้ง ZIP ก่อนแยกอีกครั้ง

## ติดตั้ง 3 ขั้นตอน
1. แตก ZIP ได้โฟลเดอร์ kranuan-system
2. หน้าแรก GitHub kranuanonlinecomunity เลือก Add file > Upload files ลากโฟลเดอร์ kranuan-system ลงไป แล้ว Commit changes
3. รอ Render ขึ้น Live แล้วกด Ctrl+Shift+R ที่หน้าแอดมินและหน้าไรเดอร์

เก็บตัวแปร Firebase/Render เดิม ไม่ต้องเปิด Firebase Rules สาธารณะ ข้อมูลรูปเก็บใน state เดิมผ่านเซิร์ฟเวอร์ มีตาราง staff_profiles เพิ่มโดยอัตโนมัติ รูปถูกย่อก่อนส่ง ไม่ต้องใช้ Firebase Storage เพิ่ม

## ผู้ดูแลใช้งาน
1. เข้า /admin.html ด้วยบัญชีแอดมิน จะพบหน้าภาพรวมใหม่ เลือก รูปและรับรองไรเดอร์
2. ค้นหาบัญชีหรือกรอง รูปใหม่รอตรวจ กด ตรวจรูป / จัดการ แตะภาพดูเต็มจอ กดอนุมัติรูป หรือให้แก้ไขรูปพร้อมเหตุผล ผู้ดูแลอัปโหลดรูปแทนพนักงานได้ด้วย
3. หลังอนุมัติรูป ติ๊ก ตรวจสอบข้อมูลบัญชีและรูปของไรเดอร์แล้ว แล้วกด บันทึกการรับรองบัญชี เอาติ๊กออกแล้วบันทึกเพื่อถอนการรับรอง

การรับรองบัญชีนี้เป็นผลตรวจโดยผู้ดูแลระบบ ไม่ใช่การตรวจจากหน่วยงานภายนอก ไม่เปลี่ยนสิทธิ์รับงานอัตโนมัติ

## ไรเดอร์ใช้งาน
เข้าระบบด้วยบัญชีไรเดอร์ ไปตั้งค่า แตะไอคอนกล้องที่รูปโปรไฟล์ เลือกรูป JPG/PNG/WebP ระบบย่อและส่งเข้าฐานข้อมูลกลางให้ทันที ไม่จำเป็นต้องกดบันทึกรูปซ้ำ รอตรวจแล้วจะแสดงผลตรวจและเหตุผลแก้ไขในหน้าตั้งค่า รูปประกอบพนักงานทั้ง 4 ช่องบันทึกส่วนตัวในระบบกลางและผู้ดูแลเปิดดูได้ ไม่แสดงให้ลูกค้า

รูปโปรไฟล์ใหม่แสดงให้เจ้าของบัญชีและผู้ดูแลเห็นระหว่างรอตรวจเท่านั้น ลูกค้าเห็นเฉพาะรูปที่อนุมัติและตรารับรองในหน้าติดตามออเดอร์ เปลี่ยนหรือนำรูปโปรไฟล์ออกจะถอนตรารับรองและนำรูปเดิมออกจากการแสดงต่อลูกค้า จนกว่าจะตรวจและรับรองใหม่

อัปเดตนี้ไม่ย้ายรูปเดิมที่อยู่เฉพาะเครื่องขึ้นระบบอัตโนมัติ กรุณาเลือกรูปส่งใหม่หนึ่งครั้ง ไม่มีการแตะรหัสผ่านหรือข้อมูลบัญชีธนาคาร

## ผลตรวจในเครื่อง
- ตรวจไวยากรณ์สคริปต์ 23 ส่วนผ่าน และตรวจปุ่มที่สร้างจากข้อมูลบัญชี 15 ปุ่มผ่าน
- ทดสอบ API อัปโหลดจริงในฐานข้อมูลจำลอง รูปรอตรวจส่วนตัว ป้องกันผู้ไม่มีสิทธิ์อนุมัติ ป้องกันอนุมัติรูปเวอร์ชันเก่า เหตุผลไม่ผ่าน การติ๊กรับรอง การถอนตราเมื่อเปลี่ยนรูป อัปโหลดแทนและนำรูปออก ผ่าน
- ทดสอบเส้นทางอาหาร ส่งของ ส่งคน ตลาด สต็อกและคิวไรเดอร์เดิมผ่าน
- ยังไม่ได้ติดตั้งเว็บจริงและยังไม่ได้ตรวจหน้าตาด้วยเบราว์เซอร์ในรอบนี้ ควรทดลองรูปหนึ่งบัญชีหลัง deploy ก่อนใช้งานทั่วไป
