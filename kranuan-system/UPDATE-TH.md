# คืนหน้าเรียกรถ จัดระยะขอบ และล็อกซูม

อัปเดตสะสม รวมตลาด แอนิเมชัน รูปพนักงานและรับรองไรเดอร์จากชุดก่อน

## ติดตั้ง 3 ขั้นตอน
1. แตก ZIP จะได้โฟลเดอร์ kranuan-system
2. หน้าแรก repository kranuanonlinecomunity เลือก Add file > Upload files ลากโฟลเดอร์ kranuan-system ลงไป กด Commit changes
3. รอ Render ขึ้น Live แล้วกด Ctrl+Shift+R ทุกหน้าที่เปิดอยู่ ไม่ต้องเปลี่ยนตัวแปร Firebase/Render เดิม

## การเปลี่ยนแปลง
- คืนหน้าเรียกรถแนวเดิมตามภาพ: ปุ่มส่งของ/ส่งคนสีเขียว แท็บจุดรับ/จุดส่ง ช่องค้นหา และแผนที่ปักหมุดก่อนกรอกรายละเอียด
- ลากแผนที่ใต้หมุดกลางจอ กดยืนยันจุดรับ แล้วเลือกและยืนยันจุดส่ง พิกัดส่งเข้าฟอร์มกลางที่สร้างออเดอร์จริงให้ไรเดอร์ ใช้ GPS ได้เมื่อผู้ใช้อนุญาต มีปุ่มเลื่อนและเปลี่ยนระดับแผนที่
- ค้นหาจากร้านที่มีพิกัดในฐานข้อมูลของแอป หรือกรอกละติจูด,ลองจิจูด ถ้าไม่มีสถานที่ ให้ลากแผนที่หรือกรอกที่อยู่จริงด้านล่าง ไม่มีบริการค้นหาสถานที่ทั่วประเทศในชุดนี้
- ส่งคนยังรองรับ 1 คนต่อเที่ยวตามระบบไรเดอร์ปัจจุบัน ไม่แสดงความจุ 1–4 คนตามภาพโดยไม่มีข้อมูลรถรองรับ ค่าบริการเหมาจ่ายจากเซิร์ฟเวอร์เดิม ไม่แกล้งคำนวณจากระยะทาง
- แผนที่เปิดกลางอำเภอเป็นจุดเริ่มต้นดูแผนที่เท่านั้น ยังไม่ถือเป็นพิกัดรับ/ส่งจนกดเลือกจริง
- แก้ระยะชิดขอบทุกหน้าให้มีขอบประมาณ 12–20px เนื้อหาอยู่กึ่งกลาง ช่องว่างระหว่างส่วนประมาณ 8px และปรับแถบล่างให้อยู่กลางแอป
- การ์ดร้านเป็นภาพใหญ่เต็มความกว้างพื้นที่แอป ไล่เงาดำและวางชื่อ/ที่อยู่ให้อ่านง่าย ภายในร้านใช้เมนูแถวกระชับ รูปอาหารเป็นสัดส่วน ปุ่มเพิ่มลดติดกับราคา
- ล็อกซูมหน้าเว็บผ่าน viewport และป้องกัน gesture / Ctrl+wheel / คีย์ลัดซูมในหน้าแอป โดยคงปุ่มขยายรูปในแกลเลอรีและปุ่มระดับแผนที่ไว้ การตั้งค่าช่วยการเข้าถึงหรือคำสั่งจากเมนูเบราว์เซอร์บางตัวอาจมีสิทธิ์เหนือโค้ดเว็บ

## แผนที่และข้อมูล
ใช้ภาพแผนที่จาก OpenStreetMap ตามนโยบาย https://operations.osmfoundation.org/policies/tiles/ แสดงที่มา ไม่ดาวน์โหลดล่วงหน้าหรือทำแผนที่ออฟไลน์ ขอเฉพาะภาพในจอ มีการแคชตามเบราว์เซอร์ และระบุ referrer ของรูปโดยตรง แผนที่เป็นบริการชุมชนไม่มีการรับประกันความพร้อม หากโหลดไม่ได้ยังกรอกที่อยู่และแนบ GPS ได้ ควรเปลี่ยนผู้ให้บริการแผนที่เมื่อมีผู้ใช้จำนวนมาก
ไม่มีการใช้ public Nominatim เพื่อค้นหาทั่วไปและไม่มีการส่งชื่อ ที่อยู่ส่วนตัว หรือพิกัดไป geocoding

## ตรวจสอบ
ตรวจสคริปต์และฟอร์มทั้งส่งของ/ส่งคน ปุ่มที่สร้างจาก HTML และการแปลงพิกัดไปกลับผ่าน ระบบหลังบ้านใช้ชุดเดิมที่ผ่านการทดสอบอาหาร ส่งของ ส่งคน ตลาด การยืนยันผู้ขาย คิวไรเดอร์ และรับรองบัญชีแล้ว ยังไม่ได้ติดตั้งบนเว็บจริง และยังตรวจภาพผ่านเบราว์เซอร์ไม่ได้ในรอบนี้ เพราะสภาพแวดล้อมรันคำสั่งไม่สำเร็จ
