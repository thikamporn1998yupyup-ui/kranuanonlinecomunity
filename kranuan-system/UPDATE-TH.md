# ติดตั้ง 3 ขั้นตอน
1. แตก ZIP จะได้โฟลเดอร์ kranuan-system
2. หน้าแรก GitHub repository kranuanonlinecomunity เลือก Add file > Upload files ลากโฟลเดอร์ kranuan-system ลงไป แล้ว Commit changes
3. รอ Render เป็น Live แล้วกด Ctrl+Shift+R

ใช้ทับระบบเดิมที่ติดตั้ง commerce update แล้ว เก็บตัวแปร Firebase/Render เดิม ไม่เปิด Rules สาธารณะ

เพิ่มตลาดขาย/ตามหาของ หมวดหมู่ รูปสูงสุด 5 รูป แก้ไขประกาศ ความคิดเห็น รายงานและผู้ดูแล แตะรูปจากการ์ดหรือรายละเอียดเพื่อดูเต็มจอ ปัดเปลี่ยนภาพ แตะสองครั้งขยาย

ตลาดส่งงานเข้าคิวไรเดอร์หลังผู้ขายยืนยัน ต้องเปิดส่งผ่านไรเดอร์และมีพิกัดรับของจริง กันสต็อกระหว่างรอยืนยันและคืนเมื่อปฏิเสธ รองรับเก็บเงินปลายทาง รายการราคาสอบถามให้ติดต่อผู้ขายก่อน

เพิ่มส่งคนครั้งละ 1 คน ไรเดอร์ต้องเปิดรับงานส่งคนและออนไลน์ก่อนจะเห็นงาน ใช้หน้าไรเดอร์ index (5).html และตลาด index (6).html ที่แนบมาเชื่อม API กลาง

ค่ารถเป็นราคาเหมาจ่ายจาก RIDE_FEE_THB และค่าจัดส่งตลาดจาก MARKET_DELIVERY_FEE_THB หากไม่กำหนดใช้ DELIVERY_FEE_THB เดิม หรือ 25 บาท ยังไม่คิดตามระยะทาง

ลดช่องว่างส่วนหลักเป็น 3px คงขนาดปุ่มที่แตะสะดวก คงแอนิเมชันสถานะ ให้คะแนนและทิป ทิปเป็นการแจ้งความตั้งใจ ไม่ได้โอนเงินจริง

ชื่อ ที่อยู่และพิกัดที่จำไว้เก็บในอุปกรณ์เดิม สิทธิ์เจ้าของประกาศใช้บัญชีปัจจุบันของระบบ ไม่ยืนยันตัวตน LINE อัตโนมัติ ล้างคุกกี้หรือเปลี่ยนอุปกรณ์อาจต้องเข้าสู่บัญชีเดิม

ผ่านการทดสอบ API ในเครื่อง: อาหาร ส่งของ ส่งคน ตลาด การยืนยันผู้ขาย คิวไรเดอร์ รับงานซ้ำ สต็อก สิทธิ์และการรายงาน รวมทั้งตรวจไวยากรณ์สคริปต์ทั้งหมด ยังไม่ได้ deploy เว็บจริง การตรวจภาพในเบราว์เซอร์ทำไม่ได้เพราะ localhost ไม่ตอบสนอง กรุณาทดลองหลัง deploy ก่อนเปิดรับลูกค้า
