# แก้อัปโหลดรูปและเพิ่มโปรไฟล์ไรเดอร์

อัปเดตสะสม รวมแก้มือถือ หมวดบริการ รีวิวร้าน แผนที่เรียกรถ ตลาด แอนิเมชัน และตรวจรับรองบัญชีจากชุดก่อน

## ติดตั้ง 3 ขั้นตอน
1. แตก ZIP จะได้โฟลเดอร์ kranuan-system
2. ที่หน้าแรก GitHub repository kranuanonlinecomunity เลือก Add file > Upload files ลากโฟลเดอร์ kranuan-system ลงไป แล้วกด Commit changes
3. รอ Render Live ปิดหน้าแอปหรือ LIFF แล้วเปิดใหม่ หน้าเว็บคอมกด Ctrl+Shift+R

เก็บตัวแปร Firebase/Render เดิม ไม่เปิด Rules สาธารณะ ตาราง rider_gallery และช่องข้อมูลโปรไฟล์เพิ่มอัตโนมัติเมื่อเริ่มเซิร์ฟเวอร์ ข้อมูลเดิมไม่ถูกล้าง

## เปิดโปรไฟล์ให้ลูกค้าเห็น 3 ขั้นตอน
1. ไรเดอร์เข้าสู่ระบบ ไปตั้งค่า เลือกรูปโปรไฟล์หลักและรูปแกลเลอรีได้อีก 4 รูป กรอกแนะนำตัวและพื้นที่บริการ แล้วติ๊กยินยอมเผยแพร่ กดบันทึกโปรไฟล์และการเผยแพร่
2. ผู้ดูแลเข้า /admin.html > รูปและรับรองไรเดอร์ > ตรวจรูป / จัดการ อนุมัติรูปโปรไฟล์หลักและรูปแกลเลอรีแยกทีละภาพ หากต้องการตรารับรองให้ติ๊กตรวจสอบบัญชีแล้วบันทึกด้วย การอนุมัติรูปไม่ทำให้บัญชีรับรองอัตโนมัติ
3. ลูกค้ากด ดูไรเดอร์ ในแถบหมวด เลื่อนดูภาพด้วยการปัดหรือกดลูกศร กดคนถัดไปเพื่อดูคนอื่น กดดูรูปเต็มภาพเพื่อดูภาพไม่ถูกตัด หากเป็นไรเดอร์ในออเดอร์ของตน จะมีปุ่มดูโปรไฟล์เมื่อเจ้าของเปิดเผยแพร่

รูปส่วนตัวเดิมไม่ถูกเผยแพร่อัตโนมัติ ต้องผ่านผู้ดูแลและเจ้าของบัญชียินยอมก่อน โปรไฟล์ไม่ปรากฏจนกว่ารูปโปรไฟล์หลักได้รับอนุมัติ ปิดการยินยอมและกดบันทึกเพื่อหยุดเผยแพร่ หากเปลี่ยนรูปแกลเลอรี ภาพนั้นจะถูกพักจากหน้าลูกค้าจนตรวจใหม่ การเปลี่ยนรูปโปรไฟล์หลักยังถอนตรารับรองตามกติกาชุดก่อน

## สิ่งที่แก้ในตัวอัปโหลด
- หยุดสร้างหน้าตั้งค่าใหม่ทุก 5 วินาที ป้องกันช่องเลือกไฟล์หายระหว่างเปิดคลังภาพบนมือถือ
- กันการรีเฟรชโปรไฟล์ขณะเลือกหรือส่งรูป และกันตัวอัปโหลดเก่าทำงานซ้ำกับตัวใหม่
- ย่อรูปเป็น JPEG ขนาดด้านยาวไม่เกิน 960px และลดคุณภาพให้เล็กก่อนส่ง เลือกรูปต้นฉบับได้ไม่เกิน 20 MB
- แจ้งข้อผิดพลาดการอ่านรูปและการส่งข้อมูลให้ชัด ถ้าอุปกรณ์อ่าน HEIC ไม่ได้ ให้บันทึก/ส่งออกเป็น JPG หรือ PNG แล้วเลือกใหม่
- ปัญหาการบันทึกการตั้งค่าใน localStorage ไม่ทำให้แสดงว่าอัปโหลดล้มเหลวหลังเซิร์ฟเวอร์รับรูปแล้ว สามารถเลือกรูปเดิมซ้ำเพื่อลองใหม่ได้

## ลูกค้าเห็นอะไร
ชื่อ คำแนะนำตัว พื้นที่บริการที่ไรเดอร์กรอกเอง สถานะออนไลน์ รูปที่อนุมัติ ตรารับรอง งานสำเร็จ และคะแนนรีวิวไรเดอร์จริง ถ้าไม่มีคะแนนจะแสดงขีดและ 0 รีวิว ไม่สมมติคะแนน ไม่ส่งเบอร์โทร ที่อยู่ส่วนตัว บัญชีธนาคาร หรือผู้ติดต่อฉุกเฉินออกมา รูปโหลดเฉพาะภาพที่กำลังดูผ่าน API ที่ตรวจการยินยอมและสถานะอนุมัติทุกครั้ง

## VIP 299 บาท
เตรียมการ์ดราคาและรายละเอียดไว้ให้เห็นแนวทางเท่านั้น ยังไม่รับชำระเงิน ยังสมัครหรือเลือกไรเดอร์เฉพาะคนไม่ได้ ยังไม่มีการต่ออายุและยังไม่กำหนดว่า 299 บาทเป็นสมาชิกระยะเท่าใด เซิร์ฟเวอร์ปฏิเสธคำขอเลือกไรเดอร์ที่ส่งตรงเข้ามา ก่อนเปิดจริงต้องเพิ่มระบบสมาชิก ตรวจชำระเงินจากฝั่งเซิร์ฟเวอร์ วันหมดอายุ สิทธิ์การเลือกและกรณีไรเดอร์ไม่พร้อม ระบบคิวเดิมยังทำงานตามปกติ

## ผลตรวจ
ผ่านการจำลองอัปโหลดบนมือถือ: ไม่รีเฟรชฟอร์มระหว่างเลือกภาพ ตัวจัดการไฟล์ทำงานครั้งเดียว ย่อและส่งรูปผ่าน API เลือกรูปเดิมซ้ำได้ และ localStorage ล้มเหลวไม่ทำให้การบันทึกบนเซิร์ฟเวอร์ล้มเหลว
ผ่าน API: ต้องยินยอมและอนุมัติก่อนเผยแพร่ ผู้ไม่มีสิทธิ์อนุมัติไม่ได้ ป้องกันอนุมัติภาพรุ่นเก่า เปลี่ยนรูปต้องรอตรวจใหม่ ถอนยินยอมแล้วรูป API ไม่เปิดเผย ไม่มีข้อมูลส่วนตัวในโปรไฟล์สาธารณะ และ VIP ยังล็อก
ผ่านการทดสอบเดิม: รูปพนักงาน/ตรารับรอง อาหาร ส่งของ ส่งคน ตลาด สต็อก คิวไรเดอร์ และรีวิวร้าน
ยังไม่ได้ติดตั้งเว็บจริง และเครื่องมือตรวจเว็บเข้าถึงเว็บจริงไม่ได้ในรอบนี้ จึงยังยืนยันการอัปโหลดบนมือถือเครื่องจริงไม่ได้ หลัง deploy ควรทดสอบหนึ่งบัญชีตามขั้นตอนด้านบน
