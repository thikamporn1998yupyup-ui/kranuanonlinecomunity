# แก้มือถือ หมวดบริการ ภาพย่อยและรีวิวร้าน

อัปเดตสะสม รวมหน้าเรียกรถ แผนที่ ล็อกซูม ตลาด ระบบรูปพนักงานและรับรองบัญชีจากชุดก่อน

## ติดตั้ง 3 ขั้นตอน
1. แตก ZIP จะได้โฟลเดอร์ kranuan-system
2. หน้าแรก GitHub repository kranuanonlinecomunity เลือก Add file > Upload files ลากโฟลเดอร์ kranuan-system ลงไป แล้ว Commit changes
3. รอ Render เป็น Live แล้วรีเฟรช Ctrl+Shift+R หรือปิดหน้า LIFF แล้วเปิดใหม่

เก็บตัวแปร Firebase/Render เดิม ไม่เปิด Rules สาธารณะ ตาราง shop_reviews เพิ่มอัตโนมัติ ข้อมูลเก่าไม่ถูกล้าง

## สิ่งที่ปรับ
- แก้กริดและส่วนหัวไม่ให้ดันจอมือถือ แถบหมวดหลักแบ่งแถวให้ครบทุกปุ่ม ไม่ต้องมีปุ่มตกขอบ
- การ์ดร้านเต็มความกว้างพื้นที่ใช้งาน ไล่เงาดำจากซ้ายไปขวา ข้อความจำกัดประมาณ 58% ด้านซ้าย และปล่อยด้านขวาโชว์อาหาร/สินค้า
- เพิ่มกรอบภาพย่อย 3 ช่องชิดด้านล่าง ใช้ภาพหน้าร้านและรูปเมนูจริงที่มี ถ้ารูปไม่ครบแสดงช่องไอคอนแทน ไม่สร้างภาพสินค้าปลอม แตะภาพใหญ่หรือภาพย่อยเพื่อเปิดเต็มจอ ปัดเปลี่ยนรูป แตะสองครั้งขยายรูป
- บริการ 12 ปุ่ม SVG: ทั้งหมด งานช่าง งานสวน เสริมสวย งานเอกสาร ดูแลผู้สูงอายุ ทำความสะอาด ยานยนต์ มือถือ/ไอที สัตว์เลี้ยง การศึกษา อื่น ๆ จัดกลุ่มอัตโนมัติจากคำในชื่อร้าน โดยชื่อที่ไม่ระบุประเภทชัดเจนอยู่ในอื่น ๆ หมวดที่ไม่มีข้อมูลยังไม่สร้างร้านตัวอย่าง
- การ์ดแสดงคะแนนเฉลี่ยและจำนวนรีวิวเล็ก ๆ หากไม่มีจะแสดงยังไม่มีรีวิวร้าน คะแนนร้านแยกจากคะแนนไรเดอร์เดิม
- ภายในร้านมีรีวิวล่าสุดและปุ่มเขียนรีวิว เฉพาะเจ้าของออเดอร์อาหารที่จัดส่งสำเร็จ รีวิวได้หนึ่งรายการต่อออเดอร์ เขียนซ้ำแก้ไขรายการเดิม ไม่เพิ่มจำนวนรีวิวซ้ำ

## การเพิ่มรูปให้ขึ้นสามช่อง
ผู้ดูแลใส่ภาพหน้าร้านหนึ่งภาพ และรูปเมนูอย่างน้อยสองรายการ ระบบเลือกสามภาพที่ไม่ซ้ำกัน ถ้าบริการยังไม่มีภาพประกอบให้เพิ่มข้อมูลภาพผ่านการจัดการร้าน/รายการที่มีอยู่

## ตรวจสอบ
ทดสอบ API รวมภาพจริงสูงสุด 3 รูป ไม่ปลอมคะแนน รีวิวได้หลังส่งสำเร็จและต้องเป็นผู้สั่ง ตรวจคะแนน 1–5 ป้องกันรีวิวซ้ำ ผ่าน ทดสอบแยกหมวดตัวอย่างชื่อร้านและตรวจสคริปต์ผ่าน ทดสอบเส้นทางออเดอร์อาหาร ส่งของ ส่งคน ตลาดเดิมผ่าน
ยังไม่ได้ติดตั้งเว็บจริง และยังไม่ได้ตรวจภาพผ่านเบราว์เซอร์ในรอบนี้ จึงควรเปิดตรวจบนมือถือหลัง deploy
