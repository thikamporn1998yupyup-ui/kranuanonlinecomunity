# หน้าไรเดอร์แบบผังทีม

เป็นชุดอัปเดตสะสม รวมแถบกระจก รายการย้อนหลัง 3 วัน หมวดย่อย ร้านค้า รีวิว รูปพนักงาน และโปรไฟล์ไรเดอร์จากชุดก่อน

## ติดตั้ง 3 ขั้นตอน
1. แตก ZIP จะได้โฟลเดอร์ kranuan-system
2. ที่หน้าแรก GitHub kranuanonlinecomunity เลือก Add file > Upload files ลากโฟลเดอร์ kranuan-system ลงไป แล้ว Commit changes
3. รอ Render Live ปิดแอป/LIFF แล้วเปิดใหม่ หรือ Ctrl+Shift+R บนคอม

## หน้าดูไรเดอร์
เมื่อกด ดูไรเดอร์ จะแสดงผังทีมแบบกริดรายชื่อ 2 คอลัมน์ มีรูปด้านบนและข้อมูลสั้นด้านล่าง ภาพไล่เงาดำจากซ้าย คล้ายการ์ดร้านอาหาร มีสถานะออนไลน์ ตรารับรอง จำนวนงานและคะแนนจริง แตะการ์ดคนที่ต้องการจึงเปิดหน้ารายละเอียดปัดดูรูปแบบเดิม ปิดหน้ารายละเอียดจะกลับผังทีมเดิม

ส่วนรายชื่อไรเดอร์เลื่อนได้อยู่ด้านบนของกรอบ ส่วนทีมผู้พัฒนาและบริหารถูกตรึงไว้ท้ายกรอบ ขนาดเล็ก 2 คนข้างกันเสมอ ไม่เลื่อนไปปะปนกับไรเดอร์
1. ทิฆัมพร เช้าเครือ — CEO · ผู้คิดค้นและพัฒนา
2. อนุชา จันทะดี — ผู้จัดการทั่วไป

ยังไม่ได้ใส่รูปบุคคลทั้งสอง ใช้เงาร่าง SVG และข้อความเพิ่มรูปภายหลัง ไม่สร้างภาพหน้าสมมติ เมื่อส่งภาพมาแล้วสามารถเติมช่อง photo ในรายการ window.KranuanDevelopmentTeam ที่ public/rider-team-board.js ได้

กติกายินยอมเผยแพร่และอนุมัติรูปยังใช้เหมือนเดิม ไม่มีโปรไฟล์ทดลอง VIP 299 บาทยังเป็นรายละเอียดแผนอนาคต ไม่เปิดรับเงินหรือเลือกไรเดอร์จริง

## ตรวจสอบ
ตรวจไวยากรณ์สคริปต์ใน ZIP และจำลองหน้า: เปิดผังทีมก่อน หน้ารายละเอียดเปิดเฉพาะเมื่อระบุไรเดอร์ รายชื่อผู้พัฒนาสะกดตามที่กำหนด และส่วนทีมผู้พัฒนายังอยู่แม้ไม่มีไรเดอร์ ผ่าน ยังไม่ได้ติดตั้งเว็บจริงและยังไม่ได้ตรวจภาพบนมือถือจริง
