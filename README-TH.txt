เปิดเส้นทางตามถนนด้วย Geoapify Free:
1. สมัคร/สร้างโปรเจกต์ที่ https://myprojects.geoapify.com/ และรับ API key ของคุณ
2. Render > บริการ kranuanonlinecomunity > Environment > Add Environment Variable
   ชื่อ: GEOAPIFY_API_KEY
   ค่า: API key ของคุณ
   ไม่ส่ง key ในแชต ไม่ใส่ในไฟล์ JavaScript และไม่อัป key เข้า GitHub
3. ใช้ Build Command: npm install --omit=dev
   ใช้ Start Command เดิม: node dispatch-start.cjs
   เลือกบันทึกพร้อม rebuild/deploy เพื่อให้ติดตั้งตัวตรวจคลิปด้วย
   package-lock.json เดิมไม่ได้ปรับในชุดนี้ เพราะสภาพแวดล้อมจัดทำไฟล์ติดต่อ npm registry ไม่ได้; build ต้องใช้ npm install ตามข้างบน ไม่ใช้ npm ci
4. คง Environment Variables เดิมทั้งหมด โดยเฉพาะ Firebase

Geoapify Free มีโควตา ไม่ใช่ไม่จำกัด: เอกสารระบุ 3,000 credits/วัน และคิดเส้นทางตามจำนวนช่วงการเดินทาง
โมดูลจำกัดเบื้องต้นไว้ 2,400 credits/วัน/โปรเซส, แคช 5 นาที และจำกัดความถี่รายบัญชี
ตัวนับภายในรีเซ็ตเมื่อเซิร์ฟเวอร์รีสตาร์ต ให้ตรวจโควตาจริงใน Geoapify ด้วย
API key เก็บฝั่งเซิร์ฟเวอร์; แผนที่แสดง attribution Geoapify/OpenStreetMap
เส้นทางใช้ motorcycle ตามถนนที่ผู้ให้บริการแนะนำ ระยะ/เวลาเป็นประมาณการ ไม่ใช่มิเตอร์ระยะรถวิ่งจริง และขึ้นกับข้อมูลถนน
ถ้าขาด GPS พิกัดลูกค้า หรือ API ใช้งานไม่ได้ จะแจ้งข้อผิดพลาด ไม่ใช้เส้นตรงปลอมเป็นระยะถนน

สิ่งที่เปลี่ยน:
- หน้าแรกโทนสว่างเริ่มต้น แผนที่ด้านบนเต็มความกว้าง มีเงาให้อ่านข้อมูลได้
- ค่ารอบจากงานสำเร็จวันนี้และปุ่มออนไลน์/ออฟไลน์ด้านบน
- ตัดการ์ดคุ้มไม่คุ้มออกจากหน้าแรก; คำนวณระยะ ต้นทุน และเงินเหลือโดยประมาณในป๊อปอัพงานเข้า
- ไม่รวมราคาสินค้าลูกค้าเป็นรายได้ไรเดอร์ และไม่เปลี่ยนค่ารอบจริง
- ตั้งค่าน้ำมัน ค่าใช้รถ ระยะเผื่อ เป้าเงินเหลือ และโหมดสว่าง/มืดในหน้าตั้งค่า
- เมนูงานเปลี่ยนเป็นข่าวสาร; งานรอรับ/กำลังส่งยังเข้าจากหน้าแรกได้
- ข่าวสารเป็นกระดานกลุ่มส่วนตัวสำหรับไรเดอร์/แอดมิน รีเฟรชประมาณทุก 10 วินาที แบ่งหน้า 50 ข่าว
- ส่งข้อความ รูป JPG/PNG/WebP ที่บีบอัดได้ และ MP4/WebM ไม่เกิน 5 วินาที/1 MB; ปุ่มอัดคลิปใช้กล้อง ไม่อัดเสียง
- แอดมินเข้าหน้า admin เดิม แล้วกด “ข่าวสารไรเดอร์” เพื่อซ่อน/แสดง ปักหมุด และลบถาวร
- รูปจำกัด 400 KB; ข้อมูลข่าวสารรวมจำกัด 8 MB ให้แอดมินลบข่าว/สื่อเก่าเมื่อเต็ม ไม่มีการลบอัตโนมัติ

ข้อมูลและการซิงก์:
ใช้บัญชี session สิทธิ์ CSRF และ order/presence เดิม ไม่เปลี่ยน schema งาน ไม่เปลี่ยน server.cjs
ข่าวสารเก็บแยกใน Firebase Realtime Database: /kranuanonline/rider_hub_v1/state ผ่าน backend เดิม
อ่านได้เฉพาะไรเดอร์และแอดมิน; จัดการข่าวได้เฉพาะแอดมิน
โหมดและต้นทุนเก็บในเครื่อง/เบราว์เซอร์ของไรเดอร์ ไม่ใช่การตั้งค่ากลางข้ามเครื่อง
ลูกค้าเป็นจุดส่งที่บันทึกในงาน ไม่ใช่การติดตามตำแหน่งสดของลูกค้า

หลัง deploy ให้ตรวจด้วยบัญชีทดสอบก่อนรับงานจริง:
- เปิด /rider/ อนุญาต GPS ตรวจแผนที่ จุดไรเดอร์ จุดรับและจุดส่ง
- ทดลองออนไลน์/ออฟไลน์ ตรวจในหน้าแอดมินว่าตรงกัน
- ส่งงานทดสอบ ตรวจ popup ระยะตามถนน/ต้นทุน แล้วรับงาน-รับของ-ส่งสำเร็จ และตรวจค่ารอบ
- เปลี่ยนธีมและต้นทุน ออกจากหน้าแล้วกลับมาตรวจ
- ส่งข้อความ รูป คลิปสั้นจริง และคลิปเกิน 5 วินาที (ต้องถูกปฏิเสธ)
- แอดมินทดลองซ่อน/แสดง/ปักหมุด/ลบข่าวทดสอบ

ข้อจำกัดการตรวจชุดนี้:
ผ่านการทดสอบอัตโนมัติ 36 จุดด้วยฐานข้อมูลแยกและบริการเส้นทาง/ตัวตรวจคลิปจำลอง
ผ่านทดสอบ UI จริงในเบราว์เซอร์พร้อมข้อมูลจำลอง ที่กว้าง 320,390,768 พิกเซล ไม่มีล้นด้านข้าง
ยังไม่ได้ทดสอบ API key ของคุณ, GPS มือถือจริง, ไทล์แผนที่จริง และการติดตั้ง ffprobe/คลิปจริงบน Render
จึงยังไม่ถือว่าผ่านทดสอบใช้งานจริงครบวงจร ภาพตัวอย่างใช้ข้อมูล/แผนที่จำลอง

ย้อนกลับ:
คืนไฟล์เดิมทั้งชุดจาก backup/commit ก่อนหน้า แล้ว deploy ใหม่ อย่าลบ Firebase ข้อมูลจริง
ข่าวสารใหม่เก็บแยกจากระบบงานเดิม ไม่ต้องแก้ฐานข้อมูลงานเพื่อย้อน UI
